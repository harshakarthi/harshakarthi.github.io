# Harsha Karthikeyan – Portfolio

**Live site:** https://harshakarthi.github.io

My personal portfolio as a .NET Software Engineer. It covers my career at Optum,
key pieces of work from a healthcare SaaS platform that sends 30M+ notifications a year,
and my skills and certifications.

## What's on the site

- **Career** – a timeline of my roles at Optum and the skills I gained in each
- **Highlights** – case studies of real work, each opening in a pop-up with the problem, what I did and the result
- **Skills, education and certifications**
- **Contact** – email and LinkedIn

All case studies are written descriptions. No company code or confidential information is included.

## Built with

- HTML, CSS and plain JavaScript (no frameworks or build step)
- Native `<dialog>` element for the case study pop-ups
- Responsive layout and hosted on GitHub Pages

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Page content and case studies |
| `style.css` | Layout, colours and responsive styles |
| `script.js` | Pop-ups, copy email button and top bar behaviour |
